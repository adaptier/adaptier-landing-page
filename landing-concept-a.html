// Deployment

Up in three steps.

From bare metal to live data in minutes, not days.

01

Configure in the UI

Add your Modbus/M-bus/OPC-UA devices in the browser. Scan the bus to auto-discover meters. Map registers to named data points. Save — config goes live instantly via NATS KV.

02

Deploy to the edge

Run adaptier-agent deploy app.zip --node pi-01. The 850 KB runtime boots in under 2 seconds on a Raspberry Pi. Rollback in one command.

03

Data flows to NATS

Every poll reading publishes to NATS JetStream in real time. Connect dashboards, historians, PLC logic, or your own consumers — all via standard NATS subjects.
